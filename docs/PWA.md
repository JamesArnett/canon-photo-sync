# PWA and iPhone

Open the trusted HTTPS app URL in Safari while on the home network. Use Safari's Share menu → **Add to Home Screen**, enable **Open as Web App** where offered, and launch it from that icon. Sign in again if the standalone WebKit context has a separate session. Dashboard polling runs every five seconds while visible, with a foreground refresh. Offline mode shows the public app shell and clears protected view state. The icon and manifest apply to new installs. Deployment changes should bump the service-worker cache key when the shell changes.

For iOS and iPadOS Web Push, use a Home Screen installation on 16.4 or later. Visit **Settings → Notifications** inside the app and tap **Enable notifications**. Set a name, event choices and optional quiet hours. Use **Send test notification** and check Activity for provider submission. [WebKit iOS Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)
