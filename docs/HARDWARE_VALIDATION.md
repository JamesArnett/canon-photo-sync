# First physical validation

Cloud checks use generated bytes and synthetic providers. Record model, firmware, DSM build, SSO package version, Node version, volume type, iOS version and adapter/reference revision before each hardware run.

1. Check for **Camera Control API** in the Wi-Fi settings and, if absent, confirm activation support with Canon. Use the bundled read-only adapter. [Camera setup and reconnection](CCAPI_RESEARCH.md#first-connection) Verify the exact serial and that a different camera at a reused IP cannot import.
2. On the EOS R6 Mark II with firmware 1.7.0, configure infrastructure Wi-Fi and verified certificate/authentication policy. Verify both SD slots, all enabled original formats and multiple pages. Compare original bytes against copies taken directly from cards. Check filename reset and card reformat tests using expendable test media.
3. Shoot while downloading. Power off during enumeration and active import, sleep the camera, wake and reconnect, and power-cycle it. Record whether the connection profile resumes automatically and whether polling alters sleep/battery behavior.
4. On the DS1525+, verify the Node runtime and SQLite backend, non-root account, hard links and directory fsync on the actual volume. Test limits and permission failures on a disposable import tree. Restart mid-transfer and verify no incomplete original or duplicate. Move a completed file and confirm it stays deduplicated. Reboot DSM and confirm the boot task resumes after unplugging the SSH client.
5. Verify actual SSO discovery, a permitted local account, an unauthorized account, group claims if used, MFA, PKCE, expiration and logout. Confirm HTTPS trust and denied access from outside trusted IPv4 and IPv6 networks.
6. Open iPhone Safari. Check portrait and landscape, large text, offline state, light/dark and foreground refresh. Add to Home Screen, relaunch, sign in and check app updates without reinstallation.
7. Enable notifications with an explicit tap, send a test and confirm both the submission record and actual appearance. Test quiet hours, urgency and privacy with the screen locked. Leave Wi-Fi and verify arrival over cellular while the dashboard remains restricted. Repeat on the existing VPN only if already available.
8. Measure idle and active RSS/CPU on DSM with normal NAS background workloads and a multi-gigabyte video. Verify back up and restore into a disposable state directory, including the VAPID key.
